Учебный фан-сайт вымышленного парка динозавров. В каталоге — билет в парк, две программы и три сувенира. Предложения открываются на отдельной странице; выбранный товар передаётся в форму заявки.

Цены, программы, адрес и контакты вымышлены. Проект не связан с официальным парком или правообладателями франшизы. Сервер, платежи, реальные бронирования и хранение персональных данных отсутствуют.

## Быстрый запуск

1. Распакуйте весь архив, сохранив структуру папок.
2. Откройте **welcome.html** двойным щелчком — это стартовый экран с логотипом из фильма и кнопкой **«Начнём»**.
3. Кнопка откроет **index.html** — главную страницу с hero-блоком, преимуществами и популярными предложениями.

Можно сразу открыть `index.html`. Node.js, npm, сборка и интернет для работы сайта не нужны: изображения, CSS и JavaScript лежат локально. Для просмотра через сервер можно использовать Live Server в VS Code либо выполнить в корне проекта:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000/welcome.html`. Сервер запускается только для локального просмотра, backend-заявки он не обрабатывает.

## Что изменилось относительно КР №1

Это отдельная реализация на Bootstrap, а не наложение фреймворка на прежний `style.css`. Тематика компьютерной техники заменена парком динозавров по заданию. Сохранён сценарий учебного магазина: каталог → карточка → заявка, а также общая навигация, характеристики, формы и единое оформление. Дополнительно есть билеты и программы посещения. Исходные файлы первой работы не изменены.

В методичке `index.html` определён как главная с hero, преимуществами и популярными товарами. Поэтому стартовый экран вынесен в **welcome.html**, а не заменяет обязательную главную. Обе страницы доступны из общего меню.

## Технологии и подключение Bootstrap

- HTML5, CSS3, обычный JavaScript без frontend-фреймворков.
- **Bootstrap 5.3.8 подключён локально**, без CDN во время работы сайта.
- `vendor/bootstrap/css/bootstrap.min.css` — готовые стили и сетка.
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — компоненты и Popper.
- `css/custom.css` подключён **после** Bootstrap и задаёт палитру, hero, оформление изображений и небольшие дополнения.
- Лицензия Bootstrap сохранена в `vendor/bootstrap/LICENSE`.

Официальные источники:

- [Bootstrap Quick start](https://getbootstrap.com/docs/5.3/getting-started/introduction/)
- [Bootstrap Grid](https://getbootstrap.com/docs/5.3/layout/grid/)
- [Bootstrap Modal](https://getbootstrap.com/docs/5.3/components/modal/)

Файлы взяты из пакета `bootstrap@5.3.8`; их SHA-384 сверены с официальным Quick start. В самом HTML используются только локальные пути.

## Самостоятельные расширения относительно базового примера

1. Отдельный стартовый экран, классический красно-жёлтый логотип Jurassic Park и шесть связанных страниц.
2. Локальная поставка Bootstrap и всех изображений; нет внешних шрифтов и ресурсов.
3. Поиск по названию и описанию, фильтр категории, сортировка по цене и названию, сброс и сообщение пустого результата.
4. Отдельные сведения о каждом предложении через `product.html?id=amber` и аналогичные ссылки.
5. Передача выбора через `order.html?product=amber`; неизвестные значения безопасно обрабатываются.
6. Расчёт стоимости по количеству, дата для посещений и выбор времени для программ. Для сувениров эти поля скрыты и отключены.
7. Проверка обязательных полей, имени, e-mail, 10 цифр телефона, диапазона количества, даты и согласия. Результат в Bootstrap Modal без отправки данных.
8. Карточки одной высоты, фотореалистичные изображения в едином стиле, кинематографичная главная и единая палитра.
9. Адаптивные колонки, сворачиваемое меню, видимый фокус, связки `label`/`id`, осмысленные `alt`, skip-link и `prefers-reduced-motion`.
10. Таблицы характеристик и FAQ на Bootstrap Accordion; документация для проверки и защиты.

## Проверка проекта

Проверка структуры без дополнительных библиотек:

```bash
python tests/check_structure.py
```

Необязательные тесты JavaScript в DOM-среде:

```bash
npm install --no-save --package-lock=false jsdom@26.1.0
node tests/behavior.cjs
```

`node_modules` исключён через `.gitignore` и не нужен для просмотра сайта. Скрипты проверяют структуру, пути, формы, фильтры, расчёт и Bootstrap-события. Они **не заменяют визуальную проверку браузером**. Результаты и ручной сценарий находятся в [docs/CHECKS.md](docs/CHECKS.md).

## Корректировки второй версии

- Самодельная эмблема заменена классическим красно-жёлтым логотипом из фильма. Файл загружен локально без перерисовки; источник указан в `docs/ASSETS.md`.
- Все шесть SVG-картинок карточек заменены фотореалистичными PNG: для посещений — динозавры, для сувениров — предметные изображения. Палитра, освещение и окружение согласованы с главным фоном.
- В тесных карточках кнопка переносится, длинные метки не выходят за изображение, логотип масштабируется. Выравнивание раскрытого меню согласовано с `navbar-expand-xl`.
- Карусель не добавлена: в разделах 5 и 9 КР №2 требуется дополнительный компонент **по выбору**. Уже реализованный Accordion выполняет это требование.
- Адаптивность проверена по HTML/CSS; DOM-тесты проверяют раскрытие меню. Реальный браузерный рендеринг пока не проверен из-за недоступного предпросмотра. Подробности — `docs/RESPONSIVE.md`.
