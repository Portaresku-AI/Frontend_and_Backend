## Запуск

1. Распакуйте архив целиком, сохранив вложенные папки.
2. В терминале перейдите в папку проекта, где лежит `index.html`.
3. Запустите локальный статический сервер:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

На Windows при необходимости используйте `py -m http.server 8000 --bind 127.0.0.1`. Альтернатива — расширение Live Server в VS Code.

Откройте `http://127.0.0.1:8000/welcome.html` или сразу `http://127.0.0.1:8000/index.html`. Все изображения и исходники локальные; npm и сборка для запуска не нужны. Сервер остановится по Ctrl+C. Он только отдаёт файлы и не обрабатывает заявки. Для двух версий используйте разные порты, например 8000 и 8001.

HTML также открывается двойным щелчком, но HTTP рекомендуется для одинакового поведения браузеров; сохранение `localStorage` для `file://` не гарантируется.

## Адаптивные решения

- На всех шести страницах есть viewport; `responsive.css` подключён после `style.css`.
- Mobile First: начальная сетка одноколоночная. От 640 px карточки и форма получают две колонки; от 768 px изображение и описание товара стоят рядом; от 1024 px каталог получает боковую панель; от 1280 px каталог показывает три карточки в ряд.
- Flexbox используется в шапке, меню и группах кнопок; Grid — в каталоге, форме, описании товара и подвале.
- Мобильное меню использует нативные `details/summary`: работает с клавиатуры и без JS. С 1024 px показывается полное меню. Скрытая версия не попадает в порядок Tab.
- Фильтр на телефоне расположен над карточками, параметры раскрываются отдельно; на desktop панель sticky. Категории ведут к разделам каталога.
- На телефоне характеристики показаны как `dl/dt/dd`; от 640 px — семантическая таблица с caption и scope. Широкая таблица прокручивается внутри контейнера, не растягивая страницу. Одновременно доступно только одно представление.
- Формы растягиваются по контейнеру; поля и кнопки имеют удобную высоту. Длинный адрес почты переносится, дочерним блокам сетки задан `min-width:0`.
- `max-width:100%`, WebP, picture, srcset и sizes адаптируют изображения. Hero использует отдельное изображение, поверх которого расположен градиент для читаемости.
- `prefers-reduced-motion` отключает декоративные переходы, добавлены стили печати.

## Доступность и исправления

На каждой странице один h1, логичная иерархия заголовков, семантические header/nav/main/footer. Исправлена структура исходной главной: footer находится после main. Есть skip-link, заметная рамка `:focus-visible`, `aria-current` в меню, осмысленные alt, связанные label/id и подписи форм.

Необязательные ARIA удалены: доступное имя ссылки-логотипа складывается из alt и видимой подписи. Сообщения не перекрывают интерфейс. Нативный dialog открывается через `showModal()`, закрывается по Esc и кнопке, возвращает фокус инициатору; обработчик Tab замыкает фокус внутри, в том числе при одной кнопке.

## Что намеренно остаётся статическим

В КР №3 карточки записаны в HTML, категории — якорные ссылки. Поля макета фильтра отключены и помечены как макет. Расчёт суммы, JS-поиск, сохранение корзины и расширенная валидация относятся к КР №4. В КР №3 формы используют встроенные ограничения HTML; после успешной проверки показывается учебное окно результата. Дата и время здесь не управляют реальным бронированием.
