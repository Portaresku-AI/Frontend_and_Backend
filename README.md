# Учебный проект по дисциплине «Фронтенд и бэкенд разработка»

## Описание

Данный репозиторий содержит выполненные практические и контрольные работы в рамках дисциплины «Фронтенд и бэкенд разработка».

Проект представляет собой монорепозиторий, в котором собраны несколько независимых учебных заданий. Для удобства навигации в корне проекта создана стартовая страница.

## Структура репозитория

| Файл или папка | Содержимое |
| --- | --- |
| `index.html` | Главная страница репозитория (меню для перехода к работам) |
| `ControlWork-N1-051026/` | Папка с контрольной работой №1 |
| `Practice-N1-140926/` | Папка с практической работой №1 |
| `.gitignore` | Файлы, исключённые из Git |
| `README.md` | Общее описание репозитория |

## Содержание работ

### Практическая работа №1
Тема: «Создание Git-репозитория и публикация проекта».
- Создан Git-репозиторий и настроена связь с GitHub.
- Разработан HTML-каркас стартовой страницы.
- Выполнено базовое CSS-оформление.
- Проект успешно опубликован на GitHub Pages.

### Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».
- Разработан учебный магазин компьютерной техники «КомпМаркет».
- Реализована семантическая разметка, Grid и Flexbox, таблицы, формы.
- Использованы CSS-переменные, псевдоклассы, БЭМ и различные типы позиционирования.
- Проект успешно опубликован на GitHub Pages.

## Технологии

HTML, CSS и минимальный JavaScript без библиотек и фреймворков. Для публикации предусмотрены Git, GitHub и GitHub Pages.
