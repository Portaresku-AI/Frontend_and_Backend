## Технологии

HTML, CSS и минимальный JavaScript без библиотек и фреймворков. Для публикации предусмотрены Git, GitHub и GitHub Pages.

## Основные требования

- На каждой странице есть шапка, меню, один `main`, подвал и уникальный `title`.
- Использованы `section`, `article` и `aside`.
- Якорные ссылки ведут к преимуществам, категориям и отдельным товарам.
- Карточки расположены через Grid. Меню и кнопки используют Flexbox.
- Таблицы содержат `caption`, `thead`, `tbody`, `th` и `td`.
- У полей формы есть `label`, `id` и `name`; обязательные поля используют `required`.
- Почта проверяется через `type="email"`, телефон — через `pattern` на 11 цифр.
- В CSS есть переменные, `:hover`, `:focus-visible` и `:disabled`.
- Пример БЭМ: `card`, `card__price`, `card--new`.
- Бейдж использует `absolute` внутри контейнера с `relative`. Панель фильтров использует `sticky`, кнопка «Наверх» — `fixed` и `z-index`.

## Небольшие доработки

Вместо одной карточки сделан каталог из трёх товаров. На странице `product.html` у каждого товара есть свой раздел с характеристиками; ссылка «Подробнее» ведёт сразу к нему. Добавлены категории с якорными ссылками, бейджи, локальные SVG-рисунки, кнопка «Наверх» и один медиазапрос для узкого экрана.

## Ограничения

Фильтры статические и не применяются к каталогу. Категории работают как ссылки к разделам, а не как фильтрация.

Сайт не принимает настоящие заказы. После встроенной проверки формы JavaScript отменяет обычное действие и открывает окно результата. Данные не отправляются на сервер и не сохраняются. Метод `dialog` у основной формы, расположенной вне диалога, также не выполняет отправку при отключённом JavaScript. У форм внутри окон этот же метод закрывает диалог.

Проверка телефона подтверждает только наличие 11 цифр, а не существование номера. Серверная часть, корзина и оплата в эту контрольную не входят.
